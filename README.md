# Total Pitch Analytics ⚽📊

A Python-based data analytics suite designed to visualize and analyze football (soccer) passing patterns, player positioning, and match dynamics.

## 🚀 Overview
This project focuses on transforming raw match event data into actionable insights. By leveraging spatial data, we can identify key playmakers, high-traffic zones, and passing efficiency.

## 🛠️ Features
* **Passing Networks:** Visualize how players interact and identify the "hub" of the team.
* **Heatmaps:** Track player movement and ball density across different pitch zones.
* **Pass Analysis:** Detailed metrics on pass completion rates, progressive passes, and key passes.
* **Pitch Visualization:** Standardized pitch plotting using `mplsoccer`.

## 📦 Tech Stack
* **Language:** Python 3.x
* **Data Handling:** `pandas`, `numpy`
* **Visualization:** `matplotlib`, `seaborn`, `mplsoccer`
* **Data Sources:** Compatible with StatsBomb, WyScout, or Opta event data.
